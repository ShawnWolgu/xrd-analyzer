# XRD 分峰与拟合模型

本文档说明 XRD Analyzer 当前采用的科学模型和标准分析流程。它用于统一软件维护、结果解释和论文方法描述；具体实验仍需由使用者判断峰归属、背景处理、拟合区间和约束是否合理。

## 1. 分析流程

一次完整分析按以下顺序进行：

1. **加载与合并数据**：读取两列数据，横坐标为衍射角 `2theta`（degree），纵坐标为强度。加载模块中的范围裁剪会永久移除本项目范围外的数据；多个扫描之间未覆盖的区间保留为缺失值，不参与拟合。
2. **数据预处理**：可对每个连续有效数据段进行 Savitzky–Golay、高斯或 FFT 滤波，并可扣除多项式或 SNIP 背景。预处理始终从不可变的原始数据重新计算，避免重复操作累积改变数据。
3. **建立峰的初始配置**：通过自动寻峰、直接输入 `2theta`、点击图像或由理论晶面间距反算峰位来添加峰。峰名和 film/substrate 类型是人工给定的分析信息，不由角度顺序自动推断。
4. **建立拟合模型**：使用一个非负常数背景和若干 Pseudo-Voigt 峰的线性叠加描述实验曲线。
5. **选择拟合数据与目标函数**：使用者可设置本轮拟合的包含或排除区间，并选择 Linear、Log 或 Mixed 目标。拟合区间只生成掩码，不删除已经加载的数据。
6. **施加参数约束并优化**：每个峰可设为优化、冻结或禁用，也可单独固定峰位、峰高或 FWHM。优化由 lmfit 调用所选数值求解器完成。
7. **检查并接受结果**：检查曲线、残差、求解器状态、参数边界命中和协方差是否可用。候选结果只有在人工接受后，才作为下一轮拟合的初始值。
8. **报告结果**：输出峰位、积分面积、峰高、FWHM、混合系数及必要的派生量，同时保存数据、配置和拟合状态以便恢复项目。

## 2. 拟合模型

在衍射坐标 \(x=2\theta\) 上，总强度写为

\[
I_{\mathrm{calc}}(x)=C+\sum_{i=1}^{N}P_i(x),
\]

其中 \(C\ge 0\) 为常数背景，\(P_i\) 为第 \(i\) 个 Pseudo-Voigt 峰。当前模型不包含随角度变化的背景项；如已在预处理阶段扣除背景，拟合背景通常接近零，但仍可由使用者固定或优化。

### 2.1 Pseudo-Voigt 峰形

软件使用 `lmfit.models.PseudoVoigtModel` 的归一化定义：

\[
P(x)=A\left[(1-\eta)G(x;\mu,\sigma)+\eta L(x;\mu,\sigma)\right],
\]

\[
G(x;\mu,\sigma)=\frac{\sqrt{\ln 2/\pi}}{\sigma}
\exp\left[-\ln 2\left(\frac{x-\mu}{\sigma}\right)^2\right],
\]

\[
L(x;\mu,\sigma)=\frac{1}{\pi}\frac{\sigma}{(x-\mu)^2+\sigma^2}.
\]

Gaussian 和 Lorentzian 分量具有相同的半高宽，因此

\[
\mathrm{FWHM}=2\sigma.
\]

峰顶高度为

\[
H=\frac{A}{\sigma}
\left[(1-\eta)\sqrt{\frac{\ln 2}{\pi}}+\frac{\eta}{\pi}\right].
\]

这里的 \(A\) 是扣除拟合背景后的**积分面积**，不是峰高。固定峰高时，软件通过上式约束 \(A\)，使 \(\sigma\) 或 \(\eta\) 改变时峰高仍保持设定值。

### 2.2 主要变量

| 变量 | 软件参数 | 含义与单位 | 当前约束 |
|---|---|---|---|
| \(\mu\) | `center` | 峰位，单位为 degree `2theta` | 位于该峰的人工搜索边界内 |
| \(A\) | `amplitude` | Pseudo-Voigt 积分面积，强度 × degree | \(A\ge 0\) |
| \(H\) | `height` | 峰在 \(x=\mu\) 处的净高度 | 由 \(A,\sigma,\eta\) 计算 |
| \(\sigma\) | `sigma` | 共同半高半宽，单位为 degree `2theta` | film: 0.01–1.50；substrate: 0.01–1.00 |
| FWHM | `fwhm` | 半峰全宽，单位为 degree `2theta` | film: 0.02–3.00；substrate: 0.02–2.00 |
| \(\eta\) | `fraction` | Lorentzian 面积分数 | \(0\le\eta\le1\) |
| \(C\) | `c` | 常数背景强度 | \(C\ge0\)，也可固定 |

“冻结”会固定一个峰的 \(\mu,A,\sigma,\eta\) 整个峰形；“禁用”会令其面积为零。可选的薄膜峰 FWHM 相等约束令参与优化且未单独固定宽度的薄膜峰共享同一 \(\sigma\)。最小峰间距约束作用于相邻优化峰的中心，而不是只检查初始峰位。

## 3. 优化目标

只对本轮拟合掩码内且数值有限的数据点进行优化。令观测值为 \(I_j\)，模型值为 \(\hat I_j\)，本轮观测强度的最大绝对值为

\[
S=\max_j |I_j|,
\]

当 \(S=0\) 时取 \(S=1\)。三种目标的残差定义如下。

### Linear

\[
r_j^{\mathrm{lin}}=\frac{I_j-\hat I_j}{S}.
\]

Linear 目标更强调绝对强度较高的数据点，因此很高的基底峰可能主导优化。

### Log

\[
r_j^{\log}=\log_{10}(I_j+I_0)-\log_{10}(\hat I_j+I_0),
\]

其中 \(I_0>0\) 是使用者设定的强度底值。Log 目标提高了弱峰和低强度区的相对影响；参与拟合的数据或模型出现负强度时不能使用该目标。

### Mixed

令 \(w\in[0,1]\) 为 Log 权重，软件将两组加权残差拼接后最小化：

\[
\mathbf r^{\mathrm{mix}}=
\begin{bmatrix}
\sqrt{1-w}\,\mathbf r^{\mathrm{lin}}\\
\sqrt{w}\,\mathbf r^{\log}
\end{bmatrix}.
\]

因此 \(w=0\) 等价于 Linear，\(w=1\) 等价于 Log。Mixed 是项目定义的工程目标，不应把其残差平方和直接解释为传统卡方、似然或不同目标之间可比较的 RMSE。

## 4. 结果解释

界面显示的

\[
R^2_{\mathrm{fit}}=1-
\frac{\sum_j(I_j-\hat I_j)^2}
{\sum_j(I_j-\bar I)^2}
\]

只使用本轮实际参与拟合的数据点，并始终在线性强度空间计算。它是拟合区域内的描述性诊断，不是模型唯一性或峰归属正确性的证明，也不应单独用于比较采用不同掩码的数据集。

由峰位计算晶面间距时，软件采用一级 Bragg 关系

\[
d=\frac{\lambda}{2\sin\theta},\qquad \theta=\frac{2\theta}{2}.
\]

结果报告为对应反射的“特征长度 \(d\)”。峰名中的 002、004、111、200 等仅作为人工标注；软件不会据此乘以晶面指数，也不会自动推断晶格常数、\(a/c\) 或四方度。默认波长为 Cu K-alpha-1，\(\lambda=1.5406\) angstrom，实际分析应记录所用辐射源和波长。

如计算 Scherrer 尺寸，采用

\[
D=\frac{K\lambda}{\beta\cos\theta},
\]

其中 \(\beta\) 是换算为弧度的 FWHM。若没有仪器展宽校正、可靠的形状因子和应变展宽分离，只能将其称为“表观 Scherrer 相干畴尺寸估计”，不能直接称为晶粒尺寸。

## 5. 适用边界

- 多峰重叠时，不同面积、宽度和混合系数组合可能给出相近曲线；人工峰归属、合理初值和分阶段冻结仍是必要的。
- 选择 Linear、Log、Mixed、\(I_0\)、背景处理和拟合区间属于实验分析判断，软件不会自动保证其科学合理性。
- 数值收敛不等于参数具有物理唯一性。正式使用结果前应同时检查残差、参数边界、峰形、协方差和对初值的敏感性。
- 当前测试验证了模型定义和软件行为，但完整流程尚未通过仪器标准样品或认证 PZT 数据进行独立验证。

科学验证状态和已知限制见 [scientific-validation.md](scientific-validation.md)，基准测试及更新规则见 [baseline-testing.md](baseline-testing.md)。
